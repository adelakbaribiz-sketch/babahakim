# ADR-0010: اجرای قواعد معماری در CI (Enforcement)

| فیلد | مقدار |
|---|---|
| شماره | ADR-0010 |
| وضعیت | Accepted |
| تاریخ | 1405/06/14 (2026-09-04) |
| فاز تصمیم | PHASE 03 — System Architecture |
| معادل ED | ED-44 |
| اسناد مرتبط | `ARCHITECTURE.md §6.2` · ADR-0002 (قواعد D1..D8) |

## Context

بزرگ‌ترین ریسک Modular Monolith (R1): فرسایش تدریجی مرزها — «فقط این یک‌بار مستقیم import می‌کنم» — تا معماری روی کاغذ بماند و Extraction غیرممکن شود. منشور قاعده ۲: «هر قاعده باید قابل Test باشد». قواعد D1..D8 بدون Enforce خود-اجرا نمی‌شوند.

## Options

| گزینه | مزایا | معایب |
|---|---|---|
| **A) فقط بازبینی PR** | بدون ابزار | خطای انسانی؛ ضعف با تیم کوچک و PRهای بزرگ |
| **B) ابزار Static (ESLint/depcruiser) + تست معماری در CI** | بازخورد سریع؛ قطعی؛ ارزان | راه‌اندازی اولیه |
| **C) ArchUnit-مانند جدا + Build جدا** | جامع | پیچیدگیOps بی‌مورد |

## Decision

**چهار لایه Enforcement به‌ترتیب سرعت بازخورد، همگی در مسیر Merge الزامی:**

| لایه | ابزار | چه چیزی را می‌گیرد | کجا اجرا می‌شود |
|---|---|---|---|
| ۱ | ESLint `no-restricted-imports` | import از `modules/*/domain|infra|events` (D2) | local + CI — لحظه‌ای |
| ۲ | dependency-cruiser | وابستگی بین Contextها و مسیرهای ممنوع (D2) | CI |
| ۳ | `architecture.test.ts` (bun test) | مقایسه عددی Tier `TIER[from] >= TIER[to]`، نگاشت مدل→Context، خنثی‌بودن Kernel (D1, D3, D7) | CI — همان سوئیت ۵۱ تستی |
| ۴ | Checklist بازبینی PR | موارد غیر-قابل-استاتیک (رویداد ثبت‌نشده، تفکیک Sync/Async) | Human gate |

**قاعده سخت:** نقض لایه ۱-۳ = **خطای Build** (نه هشدار). برای استثنای موقت، فقط یک مسیر مجاز وجود دارد: ثبت ردیف در فایل `docs/ARCHITECTURE.md §13` (بدهی فنی) + Task پیگیری — بدون این، استثنا ممنوع.

## Consequences

**مثبت:**
- معماری «خود-حفظ‌شونده» می‌شود؛ مرزها با رشد کد دفاع می‌شوند.
- استثناها شفاف و ردیابی‌پذیر (فهرست بدهی) نه پنهان.

**منفی/هزینه:**
- راه‌اندازی اولیه قواعد (نیم‌روز) + نگهداری جدول Tier در تست.

## Compliance

- خودِ وجود این ADR شرط Compliance است: فعال‌سازی لایه‌ها **قبل از اولین Merge بعد از فاز 03** الزامی است (Task فاز 03.5).
- اجرای `bun test` باید شامل `architecture.test.ts` باشد؛ حذف آن از CI ممنوع.
